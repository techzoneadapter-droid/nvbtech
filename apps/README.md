# NVB Tech Mobile App Directory
Website domain: https://nvbtech.com.vn/apps/

## Cách thêm một ứng dụng mobile mới
1. Tạo thư mục apps/<slug>/ với index.html, privacy.html, terms.html, support.html, google-play.html.
2. Dùng chung CSS apps/assets/apps.css và cấu trúc header/footer để đồng nhất thiết kế.
3. Đưa icon app vào apps/assets/ tên ổn định; cập nhật danh sách trong apps/index.html và từ khóa tìm kiếm data-keywords.
4. Bổ sung liên kết nếu đã có Play Store / App Store chính thức; trước khi phát hành không tạo đường dẫn giả.
5. Kiểm tra nội dung Data Safety, quyền dữ liệu, điều khoản, email hỗ trợ riêng của app; không sao chép chính sách của ReelTara sang ứng dụng khác.
6. Cập nhật sitemap nếu có; xác thực URL công khai qua https://nvbtech.com.vn/apps/<slug>/.
